1. The post

A restaurant gets 200–500 reviews a week on Google, Zomato, Swiggy and Amazon, in English, Tamil and Tanglish. Someone reads them by hand, and the food-poisoning complaint sits unread for days. So I built ReviewLens: upload the week's CSV, and every review gets tagged, the urgent ones float to the top, and a weekly report lands in the owner's inbox every Monday at 9 AM. How I built it, in 10 points: 1️⃣ Spec before code. I wrote the use-case brief, product definition, project rules and an implementation plan first (context engineering), then built it with Claude Code as my pair programmer. 2️⃣ Structured output, not free text. A LangChain LCEL chain: prompt | gpt-5.4-mini.with_structured_output(Pydantic). Literal types force sentiment, category, urgency and language into allowed values. 3️⃣ Batches that heal themselves. chain.batch() with max_concurrency=5; an invalid answer is retried twice, then flagged "needs review" instead of crashing the run. 905 reviews analysed, 0 failures. 4️⃣ Built for Tamil and Tanglish. Summaries always come back in English; replies come back in the customer's own language with an English version for staff. One prompt-order change cut wrong-language Tanglish replies from 43% to 3%. 5️⃣ Numbers come from pandas, never the LLM. The report chain returns the review IDs behind each theme; Python counts them and drops any ID the model invents. 6️⃣ Map, then reduce. One chain per review, then a report chain that sees last week's numbers and writes top complaints, top praise and 3 action items. 7️⃣ Week-over-week trends. Every week is stored in SQLite, so KPIs carry ▲▼ arrows and a heatmap shows which complaints are growing. 8️⃣ Three role workspaces. Business Owner (report, trends, email schedule), Operations Manager (upload, correct tags, manage weeks), Customer Support (urgent queue, edit replies, mark handled), with PINs per role. 9️⃣ The Monday email. A separate scheduler container sends an HTML report with trend arrows and the Excel-ready CSV, or a reminder if nobody uploaded the new week. 🔟 Shipped and tested. Docker on a Hostinger VPS behind Traefik with automatic HTTPS, plus 43 automated tests (fake LLM, fake SMTP, a headless UI test per role) that run without an API key. On a synthetic demo week, the report caught exactly what a manager should see: late-delivery complaints ▼44 after an extra evening rider, but leaking containers ▲46, so the first action item was "replace the containers".
