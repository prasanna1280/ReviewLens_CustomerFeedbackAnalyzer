# ReviewLens - Customer Feedback Analyzer

Turn hundreds of raw customer reviews (English, Tamil, Tanglish) into tagged, prioritised insights and a weekly report a manager can act on in five minutes.

Built with **LangChain** (LCEL + structured output) and **Streamlit**, using OpenAI. Brief: [`docs/USE_CASE.md`](docs/USE_CASE.md).

```
CSV upload ─► validate ─► classify each review (batched LLM) ─► aggregate (pandas) ─► weekly report (LLM) ─► dashboard + CSV export
```

Each review gets **sentiment · category · urgency · language · English summary · suggested reply**. The weekly report lists top complaints, top praise and 3 action items. Every number in it is calculated in pandas, not generated by the LLM.

## Run locally

```bash
python -m venv .venv
.venv\Scripts\activate                 # Windows  (source .venv/bin/activate on macOS/Linux)
pip install -r requirements-dev.txt
cp .env.example .env                   # then set OPENAI_API_KEY
streamlit run app.py                   # http://localhost:8501
```

Try it with **"Use sample data"**: 230 synthetic reviews from week 40, generated by `python scripts/make_sample.py`.

## Tests

```bash
pytest            # 23 offline tests, fake LLM, no API key needed
pytest -m live    # real OpenAI calls (needs .env)
ruff check .
```

## Docker

```bash
docker compose up --build              # local: http://localhost:8501
```

### Production (VPS with Traefik)

`docker-compose.prod.yml` drops the host port and adds Traefik labels (entrypoint `websecure`, Let's Encrypt resolver `letsencrypt`):

```bash
git clone https://github.com/prasanna1280/ReviewLens_CustomerFeedbackAnalyzer.git /opt/apps/reviewlens
cd /opt/apps/reviewlens
cp .env.example .env    # set OPENAI_API_KEY, APP_PASSWORD, REVIEWLENS_DOMAIN
docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d --build
```

Update after a new push: `git pull && docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d --build`

## Configuration (`.env`)

| Key | Purpose |
|-----|---------|
| `LLM_MODEL` | `openai:<model>` (default `openai:gpt-5.4-mini`) |
| `OPENAI_API_KEY` | OpenAI key, never committed |
| `MAX_CONCURRENCY` / `MAX_RETRIES` / `CHUNK_SIZE` | Batching and retry tuning |
| `MAX_ROWS` | Per-run review cap (cost guard) |
| `APP_PASSWORD` | Shared password for the web app (empty = no password) |
| `REVIEWLENS_DOMAIN` | Public hostname for Traefik |
